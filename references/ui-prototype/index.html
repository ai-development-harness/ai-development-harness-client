STEP DETAIL

STEP-017 · Live execution surface

Выполнение Harness-команды без превращения UI в альтернативный orchestration engine.

Goal

Показать incremental output, structured events, input/approval и final repository refresh.

Out of scope

Activity history, analytics, собственная state machine Harness.

Acceptance

Run переживает UI navigation; text output не становится protocol state; interactive requests продолжают тот же runtime session.

PLANcontract
IMPLEMENTadapter + UI
VERIFYdeterministic
REVIEWindependent
FIXif needed
CLOSErefresh

Evidence

Появится после implementation/verification. Источник — repository artifacts, не Activity cache.

Independent review

Mandatory. Specialized security/tests reviewers зависят от policy.

Repository history
