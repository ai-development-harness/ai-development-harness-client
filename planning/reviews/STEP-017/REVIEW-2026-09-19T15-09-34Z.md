## Findings

### F-001 — High — `O_NOFOLLOW` не удерживает весь artifact path внутри selected root

- **Location:** `apps/local-service/src/repository-projection.ts:20-40,137-149`; `docs/adr/ADR-004-bezopasnaya-git-worktree-proektsiya.md:43-45`; `apps/local-service/src/repository-projection.spec.ts:77-90`.
- **Preconditions:** selected root недоверенный и содержит symlink в промежуточном компоненте обязательного artifact path либо его path components могут изменяться во время чтения.
- **Defensive scenario:** lexical `isContained()` принимает путь под root, после чего `open(..., O_NOFOLLOW)` запрещает symlink только для последнего компонента. Промежуточный каталог остаётся разрешённым для symlink traversal, а canonical root не закреплён directory descriptor на весь цикл projection.
- **Impact:** local service может прочитать доступный ему файл вне выбранного root и вернуть его содержимое через projection. Это нарушает принятую data-only boundary и заявленное отсутствие обращений вне root.
- **Mitigation:** выполнять descriptor-relative traversal от открытого root с запретом symlink/reparse-point для каждого компонента и проверкой неизменной root identity; на поддерживаемых платформах использовать эквивалент `openat2` с beneath/no-symlink semantics. Неподдерживаемая безопасная primitive должна давать typed fail-closed result.
- **Regression test:** добавить focused case с symlink в промежуточном компоненте canonical artifact path и подтвердить отказ без чтения внешнего target; отдельно проверить replacement/root-identity mismatch.

### F-002 — Medium — FIFO блокирует `open()` до descriptor type check

- **Location:** `apps/local-service/src/repository-projection.ts:25-40`; `docs/adr/ADR-004-bezopasnaya-git-worktree-proektsiya.md:43-45`.
- **Preconditions:** обязательный artifact в недоверенном selected root представлен FIFO или заменён на него до открытия.
- **Defensive scenario:** `open()` использует `O_RDONLY | O_NOFOLLOW`; `O_NOFOLLOW` не отклоняет FIFO, а blocking open происходит раньше `handle.stat()` и проверки `isFile()`.
- **Impact:** один repository load способен бессрочно остановить local-service path, хотя ADR требует bounded failure для FIFO/special files и hangs.
- **Mitigation:** открывать artifact неблокирующим способом, затем проверять type/size на том же descriptor и немедленно отклонять non-regular file; дополнительно обеспечить bounded cancellation на уровне операции.
- **Regression test:** добавить изолированный bounded test, подтверждающий быстрый typed отказ для FIFO без зависания test process.

## Verdict rationale

Git subprocess boundary и typed security-policy result соответствуют ADR-004, а final-component TOCTOU устранён descriptor-based чтением.
