Существенных security findings в проверенном scope не обнаружено.

## Defensive threat scenarios

- **Repository-controlled Git mechanisms.** Preconditions: selected root содержит недоверенные Git config, attributes или helpers. Impact при нарушении boundary: их запуск с правами local service. ADR-004 запрещает Git subprocess для worktree и metadata, а production source не импортирует `child_process`, не читает `.git` и не вызывает Git.
- **Ложный clean/available state.** Preconditions: Git facts нельзя безопасно получить. Impact при нарушении boundary: UI может принять решения по выдуманному worktree state. Source возвращает только `{ available: false, worktree: 'unavailable', unavailableReason: 'SECURITY_POLICY' }`; branch, upstream и divergence не заполняются.
- **Ancestor/external repository confusion.** Preconditions: selected root вложен в другой Git repository или имеет нестандартную Git topology. Impact при нарушении boundary: проекция facts чужого root. Отсутствие Git discovery и fallback делает этот path fail closed; regression для nested root не использует ancestor repository.

## Verification observations

- Static search по production source `apps/local-service/src` и `packages/client-api` не обнаружил `child_process`, `exec`, `spawn` или Git invocation; `loadGit()` всегда возвращает typed `SECURITY_POLICY` unavailable.
- `packages/client-api/index.d.ts` включает `SECURITY_POLICY` в union `GitProjection.unavailableReason`; implementation typechecked через этот contract.
- Tests покрывают initialized/pre-init без Git, реальный Git repository, отсутствие upstream/divergence disclosure, nested root, configured fsmonitor и filter sentinel. Оба sentinel остаются несозданными после `loadRepository`.
- `yarn nx test local-service --skip-nx-cache` — exit code 0; 22/22 tests passed.
- `yarn nx typecheck local-service --skip-nx-cache` — exit code 0.

## Residual constraints

- Git worktree и metadata facts намеренно недоступны в MVP. Любая их активация требует отдельного capability contract, isolation design и нового independent security review.
- Tests используют Git только для подготовки isolated fixtures; эти вызовы не входят в production `ClientApi` path.

## Verdict rationale

ADR-004 закрывает как worktree, так и metadata Git subprocess для untrusted selected root. Production implementation соответствует этому decision, public `ClientApi` типизирует policy reason, а focused regressions подтверждают fail-closed behaviour. Verdict — `PASS`.
