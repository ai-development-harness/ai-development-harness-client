## Findings

- **F-001 — High — Root identity не закреплена на весь цикл projection.**
  - Location: `apps/local-service/src/repository-projection.ts:27-39,50-62,83-93,153-164`; `docs/adr/ADR-004-bezopasnaya-git-worktree-proektsiya.md:45`; `planning/tasks/STEP-017.md:79-84`.
  - Scenario: `realpath(projectRoot)` возвращает строку, после чего каждый artifact заново открывает `root` по абсолютному pathname. `O_NOFOLLOW` защищает только последний компонент конкретного `open`; intermediate компоненты самого root path могут быть заменены symlink, а root directory может быть заменён другим directory между чтением manifest, scaffold, Execution Status и STEP. В результате одна projection способна читать artifacts другого filesystem object, хотя implementation plan требует canonical root identity и regression на replacement/root-identity mismatch.
  - Impact: descriptor-relative traversal внутри одного artifact исправляет прежний intermediate symlink bypass, но не доказывает, что все artifacts принадлежат выбранному root. Untrusted concurrent mutation может вернуть смешанную projection либо прочитать другой доступный Harness root через заменённый parent path, нарушая fail-closed data boundary.
  - Fix direction: один раз открыть selected root, зафиксировать его identity (`dev`/`ino` и canonical descriptor target) и разрешать все artifact/directory operations относительно этого descriptor; при replacement или невозможности удержать boundary возвращать typed fail-closed result. Добавить deterministic regression на замену root/parent path во время load.

- **F-002 — Medium — Resource limits проверяются после уже неограниченных операций.**
  - Location: `apps/local-service/src/repository-projection.ts:50-55,83-94`; `docs/adr/ADR-004-bezopasnaya-git-worktree-proektsiya.md:45`; `planning/tasks/STEP-017.md:79-84`.
  - Scenario: размер regular file проверяется одним `fstat`, но последующий `handle.readFile()` читает до EOF без byte cap, поэтому конкурентное увеличение файла после `fstat` обходит `maxArtifactBytes`. `readdir()` сначала материализует весь attacker-controlled каталог и только затем проверяет `maxStepCount`; до 500 artifacts читаются через неограниченный `Promise.all`.
  - Impact: выбранный untrusted root может вызвать неконтролируемое потребление памяти/file descriptors и задержку local service, хотя threat model и Accepted ADR требуют bounded size/count/concurrency failure.
  - Fix direction: читать не более `maxArtifactBytes + 1` с descriptor, перечислять STEP через bounded iterator с ранней остановкой и ограничить concurrency. Добавить regressions для growing artifact и каталога, превышающего limit, которые подтверждают bounded failure до полного чтения/перечисления.
