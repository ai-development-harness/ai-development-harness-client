### F-A22 — High — Фактический success path противоречит заявленной fail-closed current policy

**Location:** `docs/research/STEP-020-linux-containment-profile.md:9,58-65,86`; `planning/tasks/STEP-020.md`; `apps/local-service/src/repository-projection.ts:245-266`; `apps/local-service/src/main.ts:1`; `packages/client-api/index.d.ts:3-5`; ADR-006:20,39.

**Scenario:** Research утверждает current `PLATFORM_UNSUPPORTED` до spawn, однако local service делает parent `realpath` и in-process filesystem I/O, возвращая successful projection; public ClientApi не содержит `PLATFORM_UNSUPPORTED`.

**Impact:** NO-GO policy фактически не действует, а untrusted selected-root boundary ADR-006 уже нарушена.

**Fix direction:** создать отдельный corrective implementation STEP: удалить либо typed fail-close текущий success path до spawn, добавить `PLATFORM_UNSUPPORTED` в owning contract/tests и доказать отсутствие selected-root I/O. До этого research должен явно описывать implementation drift, а не заявлять policy current runtime.

### F-A23 — High — Handoff не снимает полное supersede ADR-006

**Location:** ADR-007:6,19,89; `planning/tasks/STEP-019.md`; `planning/tasks/STEP-020.md:68`.

**Scenario:** После будущего profile decision ADR-007 всё ещё предполагается сделать successor ADR-006, не перенося lexical-only parent, descriptor identity, trusted spawn/isolation, immutable settlement и success-after-teardown.

**Impact:** current base security contract может исчезнуть из единственного current ADR.

**Fix direction:** в scope STEP-020 зафиксировать mandatory handoff: ADR-007 становится additive lifecycle contract, либо будущий ADR явно переносит все surviving clauses ADR-006. Нельзя принимать неизменённое тело ADR-007 как полный successor.

### F-S20 — High — Worker может обратиться к systemd user-manager control plane

**Location:** `docs/research/STEP-020-linux-containment-profile.md:21,35,58-65,82`.

**Scenario:** Компрометированный worker подключается по `AF_UNIX` к `/run/user/$UID/bus` и вызывает `StartTransientUnit`, создавая same-user process вне исходного unit; `PrivateNetwork` не скрывает filesystem socket.

**Impact:** обход limits, teardown и lease accounting с возможностью network/file access нового process.

**Fix direction:** future profile должен deny worker access к user bus/control sockets и new socket/connect capability, сохраняя supervisor IPC только на inherited bounded descriptors. Нужен runtime regression direct user-bus connection + raw `StartTransientUnit` failure; отсутствие applicable filesystem namespace = `PLATFORM_UNSUPPORTED`.

### F-A24 — Medium/High — `attachIntent` не отличён от proven child outcome

**Location:** `docs/research/STEP-020-linux-containment-profile.md:79`; ADR-007:53,55,65; `planning/tasks/STEP-002.md:65,69,87-88`.

**Scenario:** `attachIntent` durable зафиксирован, но spawn fails/crash происходит до reaper-observable child. Current oracle требует reap при любом intent и запрещает no-child proof.

**Impact:** durable availability DoS либо фиктивный release при возможном delayed spawn.

**Fix direction:** разделить durable intent и proven spawn outcome/child identity либо назвать primitive, где committed intent atomically создаёт reaper-observable child. Добавить deterministic intent-before-child and delayed-spawn regressions.

### F-T20 — High — Отрицательная NO-GO capability matrix не executable

**Location:** `docs/research/STEP-020-linux-containment-profile.md:56-65,73-82`; `planning/tasks/STEP-002.md:65,69,86`.

**Scenario:** D-Bus unavailable/unauthorized, delegated subtree отсутствует, effective limits mismatch либо нет owner/activation/receipt primitive. Handoff называет positive probes, но не требует каждое such condition проверять как pre-spawn failure.

**Impact:** future implementation может открыть unit/spawn/selected-root I/O при недоказанной prerequisite.

**Fix direction:** добавить parameterized negative capability-gate matrix: для каждого prerequisite typed `PLATFORM_UNSUPPORTED`, zero unit create/attach/spawn/selected-root I/O и no lease/capacity mutation; positive probes допустимы только после accepted profile.

### F-A25 — Medium — После NO-GO нет explicit roadmap successor

**Location:** `planning/PLAN.md:24-25,33`; `planning/STATUS.md:13,17`.

**Scenario:** STEP-020 завершится, но единственная added dependency STEP-019 будет формально satisfied, хотя NO-GO требует unavailable missing primitive/product decision.

**Impact:** critical path ошибочно возвращает работу к STEP-019 без задачи, способной снять semantic blocker.

**Fix direction:** создать explicit successor corrective/research/ADR STEP и сделать его hard dependency STEP-019; отдельно зафиксировать corrective STEP для F-A22. Обновить latest review reference STEP-019 на `REVIEW-2026-09-19T18-49-17Z.md`.
