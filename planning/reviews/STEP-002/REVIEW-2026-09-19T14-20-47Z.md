- **F-003 — Medium — Git projection может выйти за границу выбранного root.**
  - Location: `apps/local-service/src/repository-projection.ts:178-199`.
  - Scenario: Git обнаруживает ancestor checkout или использует `.git` indirection; service не сверяет `rev-parse --show-toplevel` с canonical selected root.
  - Impact: в projection попадают branch/worktree/upstream другого repository.
  - Fix direction: явно закрепить policy root identity, проверять toplevel и не проецировать Git, если он вне selected boundary; покрыть nested repository и external gitdir fixtures.

- **F-004 — Medium — открытие untrusted filesystem не имеет timeout.**

  - Scenario: FIFO или иной blocking artifact выбранного root блокирует trusted validator и `loadRepository` без ограничения времени.
  - Impact: локальный denial of service при открытии directory.
  - Fix direction: добавить bounded timeout/termination subprocess и безопасные regular-file/size проверки в verifier; покрыть blocking fixture.
